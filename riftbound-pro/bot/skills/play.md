# Play a line

Edit this procedure when you want a different default.

1. Call `lookup-card` for every card name you will quote. Use the printed cost, keywords, and text from that result.
2. If a name is missing, say so. Do not supply a cost or a rule from memory.
3. Name the decision window from what the user told you: main phase, chain priority, showdown, combat damage, or a prompt. If the window is missing, say which fact you still need.
4. Recommend one action: a play, an activation, or a pass.
5. Give the reason from the looked-up text or from a fact the user stated.
6. State when that action is wrong.
7. A legend is not a champion unit. Do not move a legend onto a battlefield or treat it as the chosen champion.

Reply in this shape:

- Action: the one play, activation, or pass
- Why: the card text or the stated fact
- Wrong when: the fact that makes this action a mistake
- Missing: facts you did not have, or "none"
